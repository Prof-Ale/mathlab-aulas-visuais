# Base de conhecimento M01 a M05

Estes documentos vieram do App Node e estão aqui como cópia de referência. Todos são **candidatas**, nenhuma foi aprovada.

- Os hashes e tamanhos de `MANIFESTO_SHA256.md` valem para estas cópias. O teste `tests/knowledge.test.js` falha se algum arquivo sumir ou mudar um byte.
- Os arquivos estão com fim de linha LF. O `.gitattributes` impede que o Git converta para CRLF, o que alteraria o hash.
- Não edite estes arquivos. Uma versão nova entra como arquivo novo, e o manifesto original é atualizado no App Node.
- Dois documentos do manifesto não foram recebidos: `02_motor_pedagogico_v2.3.6.md` e `04_design_editorial_v2.4.md` (baselines). Ficam listados em `manifest.json`, campo `conhecimento.ausentes`.
- Os dois documentos de arquitetura (Princípio da Inteligência Epistêmica e Fase 1) ficam em `docs/architecture/`.
